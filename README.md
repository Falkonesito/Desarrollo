Sistema de Gestión Operativa - INFOSER & EP SPA
Descripción del Proyecto
Este sistema fue desarrollado como una solución integral para la digitalización y optimización de los procesos operativos de INFOSER & EP SPA. La plataforma permite la gestión centralizada de solicitudes, seguimiento de servicios y visualización de métricas clave a través de un panel administrativo.

Tecnologías Utilizadas
Frontend: React.js con diseño de interfaz enfocado en la experiencia de usuario (UI/UX).

Backend: Node.js y Express para la construcción de una API RESTful escalable.

Base de Datos: PostgreSQL para la gestión de datos relacionales y persistencia.

Inteligencia Artificial: Implementación de un modelo predictivo de Machine Learning para la estimación de demanda de servicios.

Seguridad: Arquitectura de seguridad en capas, incluyendo autenticación centralizada y mitigación de vulnerabilidades comunes (SQL Injection, Brute Force).

Despliegue: Configuración y gestión de entornos en la nube mediante Render.

Funcionalidades Principales
Gestión de Solicitudes: Ciclo de vida completo de las órdenes de servicio, desde la creación hasta la finalización.

Panel de Control (Dashboard): Visualización de datos operativos en tiempo real para la toma de decisiones.

Módulo Predictivo: Análisis de datos históricos para predecir tendencias de demanda futura.

Sistema de Autenticación: Control de acceso robusto para diferentes roles de usuario dentro de la organización.

Arquitectura y Desarrollo
El proyecto fue construido bajo una arquitectura desacoplada, permitiendo que el Frontend y el Backend operen de manera independiente para facilitar el mantenimiento y la escalabilidad.

Como responsable principal del desarrollo (Full-Stack Developer), lideré las siguientes etapas:

Diseño y normalización de la base de datos en PostgreSQL.

Desarrollo de la lógica de negocio y endpoints en el Backend.

Construcción de componentes dinámicos en el Frontend con React.

Implementación y validación del modelo de Machine Learning.

Documentación técnica completa del sistema y manuales de usuario.

Estado del Proyecto
El sistema se encuentra en su fase final de documentación. Aunque el despliegue inicial se realizó en servicios de infraestructura gratuita (sujetos a limitaciones de recursos), el código fuente es completamente funcional y está listo para ser migrado a entornos de producción escalables.
